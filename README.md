# Relay Studio

Research once.
Create everywhere.

Relay Studio is an AI-powered research workspace built for knowledge creators.

Instead of switching between ChatGPT, Reddit, YouTube, Google and Notion, creators research inside one structured workspace.

## Features

- Topic Research
- URL Analysis
- Inspiration Vault
- AI Research Workspace
